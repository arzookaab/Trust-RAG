# Trust-Aware RAG Thesis Code

This repository contains the Kaggle notebooks used for the thesis proposal experiments on Trust-Aware Retrieval-Augmented Generation.

## Contents
- RQ1: Correctness and hallucination evaluation
- RQ2: Evidence reliability and adaptive weighting
- RQ3: Faithfulness verification
- RQ4: Calibration and confidence analysis
- RQ5: Selective abstention
- RQ6: Robustness under noisy and adversarial retrieval
- RQ7: Computational efficiency and scalability

## How to Run
Open the notebooks in Kaggle or Google Colab and run the cells from top to bottom.

## Main Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Transformers
- Sentence-Transformers
- FAISS
